# packages/shared

Réservé aux types et contrats partagés entre `apps/web` et `apps/api`. **Vide pour l'instant** : les types TypeScript
du frontend sont dans `apps/web/lib/types.ts` et les contrats Pydantic dans `apps/api/app`. À alimenter (par exemple
avec un schéma OpenAPI généré) lorsqu'une duplication devient coûteuse.
